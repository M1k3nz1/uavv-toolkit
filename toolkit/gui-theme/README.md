# GUI theme (visual only)

`apply_theme.py` is the script that restyled the original controller: it replaces the inline FXML colours with style classes, adds
`theme.css`, themes the dialogs, shows PX4 as the single supported flight controller, and fills the empty About dialog. It does not change
any `fx:id`, event handler or controller field. The result of running it on the original sources is what is stored in
`toolkit/java-controller/`; the script and the stylesheet are kept here so the visual change can be audited.

`InputBridge.java` (generated by the script) only matters on remote or virtual displays that report the Super key as permanently held:
it re-dispatches key events with that flag cleared, so text fields accept typing. It has no effect on a normal desktop.
