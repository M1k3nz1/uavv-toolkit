# Graphical controller: screenshots and walkthrough

Screenshots of the JavaFX campaign controller (`toolkit/java-controller`), taken on a virtual display with neutral demo files
(`survey_mission.plan`, `open_field.world`). They show the user interface only; no flight is running in them.

| File | Content |
|---|---|
| `01_home.png` | Home page: run a test campaign, execute a campaign, add a campaign |
| `02_flight_controller.png` | Step 1, flight controller under assessment (PX4 SITL) |
| `03_uav_model_mission.png` | Step 2, UAV models with their missions and the Gazebo world |
| `04_injection_process.png` | Step 3, fault target, mission type, fault type, parameters and injection window |
| `05_campaign_overview.png` | Step 4, review and generate the campaign |
| `figure_gui_annotated.png` | Step 3 with numbered call-outs (the figure used in the paper) |
| `figure_gui_steps3-4.png` | Steps 3 and 4 side by side with call-outs |
| `uavv_gui_walkthrough.mp4`, `.gif` | 20 s silent walkthrough assembled from the five screenshots (not a screen recording of a flight) |
